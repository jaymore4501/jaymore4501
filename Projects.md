# 2. INFENGINE

### AI Decision Intelligence Platform

> Transform complex decisions into confident actions with explainable AI.

**INFENGINE** is an enterprise-style Decision Intelligence platform designed to answer not only:

> "What should I do?"

but also:

> "Why is one decision objectively stronger than another?"

The platform systematically evaluates competing choices using weighted criteria, forecasting, scenario simulation, risk analysis, and explainable AI reasoning.

### Core Features

#### Multi-Model AI Reasoner

Supports reasoning through multiple AI providers/models, including:

* OpenAI
* Anthropic Claude
* Google Gemini
* Demo Mode fallback

#### Decision Dashboard

* Winner Card
* Confidence Gauge
* Option score comparison
* 14-dimensional evaluation
* Radar/Spider comparison matrix
* Decision-tree visualization
* Timeline projections

#### Sensitivity & Scenario Playground

Users can dynamically modify variables such as:

* Budget
* Risk
* Time
* Other decision weights

The platform recalculates decision scores based on changed assumptions.

### Scenario Simulation

Possible external shocks can be modeled, including:

* Market downturns
* Competitor changes
* Risk events
* Other environmental changes

### Reporting

INFENGINE can generate consultant-style PDF reports containing:

* Executive summary
* Recommended option
* Option comparison
* Radar charts
* Scoring visualizations
* Timeline forecasts
* Risk mitigations
* Cognitive-bias analysis
* Evidence chains

### GitHub

https://github.com/jaymore4501/INFENGINE

# 3. RepoGPT

### AI-Powered Repository Intelligence, Code Quality Analysis, & Architecture Visualization Platform

**RepoGPT** is a developer-focused codebase intelligence platform designed to reduce the friction involved in understanding unfamiliar repositories.

Users provide a public GitHub repository URL, after which RepoGPT can ingest, traverse, parse, analyze, and visualize the codebase.

### Core Features

#### Repository Ingestion

* Public GitHub repository cloning
* Repository traversal
* GitHub REST API integration
* Repository metadata analysis
* Commit information
* Contributor information
* Branch information
* File structure analysis

#### AST Analysis

RepoGPT extracts structural information from source code, including:

* Classes
* Functions
* Function scopes
* API routes
* Dependencies
* Imports
* Exports
* Internal relationships

Supported ecosystems include:

* JavaScript
* TypeScript
* Python
* Java
* Go
* Rust
* PHP

#### Code Quality Analytics

The platform analyzes:

* Code originality
* Duplicate code
* Language distribution
* Structural vulnerabilities
* Security risk categories
* Repository architecture

### Architecture Visualization

RepoGPT uses interactive graph visualization to represent:

* Files
* Dependencies
* Code relationships
* Architecture
* Data flows

### Semantic Code Chat

Users can ask questions about an analyzed repository.

The system retrieves relevant code context using semantic retrieval and can use:

* Ollama/local LLMs
* TF-IDF
* Cosine similarity
* Local fallback processing

### Reporting

RepoGPT generates PDF executive reports containing codebase analytics and visualizations.

### Safeguards

The platform includes rate-limiting mechanisms intended to restrict excessive repository scanning and reduce local database/file accumulation.

### GitHub

https://github.com/jaymore4501/RepoGPT

### Live Application

https://repogpt-3azy.onrender.com/

# 7. Nyxecure

### Phishing Detection & Password Diagnostics Platform

> Detect phishing URLs and analyze password strength with a modern, lightweight cybersecurity toolkit.

**Nyxecure** is a lightweight cybersecurity application focused on two common security problems:

1. Detecting potentially malicious/phishing URLs.
2. Evaluating password strength.

### URL Security Analysis

Nyxecure analyzes URLs and categorizes them into risk levels such as:

* Safe
* Suspicious
* Dangerous

It also provides URL risk scoring and security indicators.

### Password Diagnostics

The password-analysis component evaluates:

* Password strength
* Complexity
* Estimated cracking difficulty
* Security characteristics

### Dashboard

The application provides a modern security-focused dashboard for presenting analysis results.

### Purpose

Nyxecure is designed to provide an accessible first layer of security awareness for users who want to quickly inspect suspicious URLs or evaluate password quality.

### GitHub

https://github.com/jaymore4501/Nyxecure

### Live Application
